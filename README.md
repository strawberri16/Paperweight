# Paperweight
An indie horror game built using Godot 4. The game follows a meticulous accountant managing a spotless apartment. Every night, a roaring furnace breaks through the walls, bringing a screaming anomaly with it. Players must patch the structural damage and pin the nightmare back down. A dark, psychological thriller hidden behind a clean veneer.

🛠️ Tech Stack

Game Engine: Godot Engine 4

Scripting Language: GDScript

Version Control: Git + Git LFS (for large audio/3D assets)

Key Implementations:

Procedural drywall degradation and structural patching systems.

Node-based state-machine driven enemy AI.

Seamless, zero-load environmental shader transitions.
