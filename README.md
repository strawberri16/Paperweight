# Paperweight
An indie horror game built using Unity. The game follows a meticulous accountant managing a spotless apartment. Every night, a roaring furnace breaks through the walls, bringing a screaming anomaly with it. Players must patch the structural damage and pin the nightmare back down. A dark, psychological thriller hidden behind a clean veneer.

🛠️ Tech Stack

Game Engine: Unity

Scripting Language: C#
